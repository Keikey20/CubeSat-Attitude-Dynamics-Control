# CubeSat Attitude Dynamics and Control

A MATLAB-based academic project exploring attitude dynamics and control for a CubeSat.

The project covers spacecraft orientation, attitude representation and control using reaction wheels and Control Moment Gyroscopes (CMGs).

## What We Worked On

- Quaternion based attitude representation.
- Spacecraft attitude dynamics.
- Reaction wheel and CMG modelling.
- Hybrid attitude control strategies.
- Control torque allocation.
- Disturbance modelling and simulation.

## Tools & Methods

MATLAB , Attitude Dynamics , Quaternion Mathematics , Reaction Wheels , CMGs , Control Systems
